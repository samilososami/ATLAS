# Miscellaneous ATLAS tools

Small tools that keep the physical system pleasant to use and possible to fix.
They live here as source, not as private runtime state.

- [ATLAS TOUCH TYPE](atlas-touch-type/README.md): the dark touch keyboard and
  terminal docking/gesture integration.
- [RAFAS](rafas/README.md): the USB recovery shortcut, plain console and build notes.

The installation targets are deliberately explicit. Read each tool's README
before copying files onto a different machine; your paths may wear different shoes.
