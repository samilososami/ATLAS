# ATLAS Android 0.1.10-preview

Visual onboarding release.

- Replaces the tutorial placeholders with 25 page-specific ATLAS illustrations.
- Keeps the five supplied introduction assets and adds 20 matching scenes for phone control, examples and every permission.
- Uses the definitive mascot design with the blue top handle and no antenna.
- Bundles true-alpha PNGs and renders them responsively without cropping.
- Preloads only the next tutorial asset to keep navigation smooth and memory use bounded.
- Adds an automated one-to-one check between tutorial pages and packaged files.
