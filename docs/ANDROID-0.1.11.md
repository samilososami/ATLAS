# ATLAS Android 0.1.11-preview

Onboarding interaction and visual-polish release.

- Keeps the current tutorial page when Android returns from a permission dialog instead of restarting at “Bienvenido a ATLAS”.
- Shows the granted-permission button in green with the label **Permitido**, without a check mark.
- Adds restrained motion and tactile-looking 3D controls while preserving the ATLAS dark interface.
- Normalizes the apparent scale of the onboarding illustrations for smoother page-to-page transitions.
- Renews illustrations `06-phone-control.png` and `18-calendar.png` to improve clarity and consistency.
