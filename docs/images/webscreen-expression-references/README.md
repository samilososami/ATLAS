# Face design references

`14-defiant-reference.png` is the approved image-generation reference for the
local `defiant` double-applause face: restrained angry-eye geometry with only a
small upward mouth curve. It is a design input, not a runtime asset.

The implemented result is native SVG/CSS and is captured from the production
renderer at [the defiant screenshot](../webscreen-expressions/13-defiant.png).
Keeping the reference separate prevents an image bitmap from becoming part of
the live WebScreen or its microphone/Realtime path.
