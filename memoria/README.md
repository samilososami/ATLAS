# Memoria de ATLAS

Estos son los documentos editables que utiliza el lector público:

- `teorico.docx`: memoria del proyecto.
- `anexos.docx`: pruebas, planos y documentación complementaria.

Para actualizar la web, sustituye el DOCX aquí y guarda el cambio en la rama
`main`. GitHub Actions lo convierte y publica el lector automáticamente cuando
termina la reconstrucción. Editar una copia en tu ordenador no cambia la web
hasta que la subas a este directorio.

Puedes renombrarlo: `nombrecambiado.docx` tendrá el lector en
`https://atlas.samilososami.com/memoria/nombrecambiado/` y la descarga en
`https://atlas.samilososami.com/memoria/nombrecambiado.docx`.
La ruta anterior desaparece de la siguiente publicación.

Todo este directorio es público. No añadas contraseñas, credenciales ni
conversaciones personales. Los archivos PDF y HTML se generan en la rama
`memoria-web`; no hay que editarlos allí.

Detalles de publicación y solución de errores: [scripts/memoria](../scripts/memoria/README.md).
