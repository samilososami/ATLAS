# Referencia de corrección de los cascos

`headphones-solid-v2.png` es una referencia conceptual editada con la herramienta
de generación de imágenes el 17 de octubre de 2026. No es una captura de la
interfaz ni una prueba del resultado. La implementación final es SVG nativo;
véase `../renders/music_headphones.png` y sus variantes.

La referencia de entrada fue la cara existente con cascos. Se pidió conservar
la cara, posiciones, tamaño y color y cambiar únicamente los cascos.

## Prompt utilizado

> Use case: precise-object-edit. Create a corrected design reference of this exact ATLAS screen. Keep the two blue eyes, smile, spacing, size, cyan color, dark background and tiny header identical to the input. Change ONLY the headphones: the current thin wire and hollow earcups are wrong. Make the headband a smooth sturdy rounded blue band, the SAME visual thickness as the smile, not thicker. Make two SOLID filled blue ear cushions with rounded corners, about 1.6 times the old earcup width, same height. Keep a clear dark gap to either eye. Connect the band naturally to the top of each pad, no line running through pads, no extra loops. Refined minimal flat-vector-like design, no realistic materials, no shadows, no gradients beyond existing face. Do not add a head contour, facial features, text or additional objects. The character must stay recognizable as the original, not cartoonishly exaggerated.

No se atribuyen a esta referencia las otras 150 poses añadidas en esta revisión:
esas poses se definieron en geometría vectorial y se capturaron en el navegador.
