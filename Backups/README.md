# Backups

Este directorio conserva versiones funcionales que han dejado de ser la implementación principal de ATLAS. No son simples restos históricos: cada copia incluye el código necesario para estudiar la arquitectura anterior o restaurarla si una migración no se comporta como esperamos.

Las copias públicas excluyen credenciales, certificados privados, sesiones, audio, logs personales, modelos descargables y entornos virtuales. Los componentes omitidos se regeneran siguiendo la documentación de cada copia.
